# Caudate-AI-VSCODE
Caudate IDE is an AI-native desktop combining the autonomous multi-agent workflows of Antigravity IDE and the inline editing speed of Cursor — with complete freedom to run local models (Ollama, LM Studio) or any OpenAI-compatible API (OpenAI, OpenRouter, DeepSeek, Groq, vLLM) with zero mandatory sign-in or vendor lock-in.
